# India-Identity-Cards-Portal
A frontend project to simulate identity card management for Indian citizens. Users can create new identity cards like Aadhar, PAN, Driving License, PVC Cards, etc., and check the security status of existing cards. Built using HTML, CSS, JavaScript, and Bootstrap.
